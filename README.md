ICICI Bank Financial Performance Analysis

## Project Overview

An independent finance project focused on understanding ICICI Bank’s financial performance using publicly available financial results and Microsoft Excel.

## Objectives

* Understand key banking financial indicators.
* Analyze profitability and income growth.
* Compare deposits, advances, and asset quality across reporting periods.
* Practise financial calculations using Excel.

## Tools

* Microsoft Excel

## Project Status
Ongoing — learning banking concepts and developing financial analysis using Excel.
